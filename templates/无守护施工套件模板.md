# 无人值守交接摘要模板

规则唯一出处：`playbooks/08-无守护模式.md`。使用 CLI 闭环的项目直接复用其任务、日志、交接，不另建本模板文件。
旧流程项目可把以下摘要填入已有交接，无需创建启动、心跳、队列、总报告四份独立文档。

- 授权目标与来源：
- 本次范围、回滚检查点：
- 时长上限（用户给出时填写）：
- 已验收任务与证据链接：
- 仍在进行的授权任务：
- 未解决问题、需要用户判断的事项：
- 停止原因：目标完成 / 无可执行授权任务 / 等待外部条件 / 时间上限 / 用户停止。
- 唤醒条件：具体的新输入、依赖变化或新的授权。
- 分支 / commit / 推送事实：

没有变化不重复追加。不存在的任务、债务、决策不填占位表。
