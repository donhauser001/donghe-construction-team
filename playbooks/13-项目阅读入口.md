# 项目根目录阅读入口

目标：用户点击项目根目录 `东合项目进化史.html` 即可查看快照，通过页面连接实时资料与刷新；不用手动运行服务，也不等待 Agent 完工。

## 接入

在用户明确授权施工的项目里，检查入口和本机注册。缺失时执行：

```sh
bin/donghe --project <项目绝对路径> reader attach
```

只生成根 HTML 与本机 `~/.donghe/reader/` 的可重建索引/注册；不执行治理 init、不迁移 docs、不改原始任务记录、不刷新代码图谱。入口是由资料派生的阅读包；不要手工编辑。遇同名用户文件或符号链接则停止覆盖并说明。

完整安装包会注册 `donghe://workspace?id=<本机登记身份>`。根 HTML 包含离线快照与链接；用户点击连接时系统按需启动一个本项目阅读进程并打开浏览器。浏览器首次可能提示打开外部助手，不能消除系统确认。离线页面不跨域调用 localhost。已连接页面的刷新与重建有独立授权校验，只读源并更新快照，不能接受任意脚本/命令。15 分钟无阅读请求后退出，再次连接自动启动；无需管理端口。

需要由 Agent 打开时用 `reader open`；有明确刷新需求用 `reader refresh`。`reader install-helper` 仅用于安装后启动协议故障修复，不作开工仪式。

## 内容与事实

- 扫描项目 docs 下 Markdown 及根 README/AGENTS；不跟随符号链接。上限：单文档 1 MiB、总计 32 MiB、4000 文档；超限显示诊断，不声称全覆盖。
- 任务按明确 parent_focus 等归属形成任务线；没有阶段锚点的新项目可在任务卡声明 `task_line: 任务线名称`（也支持 donghe-json 同名字段）。沿用已有归属，不要求旧项目补字段。编号顺序只供浏览，不表示依赖或实际执行时间。归属缺失的留待归类；不要凭标题猜测或改写源来制造漂亮看板。
- 显式任务状态照录；进行中不代表此刻有 Agent 运行。待裁决、未验收、技术通过与最终通过不自动合并；历史文件可检索，不混入当前任务统计。
- 页面刷新重新扫描已落盘文件，不运行测试、归档、采纳、完工登记或续工。刷新失败保留旧快照并显示失败，未落盘的会话信息不可恢复。
- 两个按钮目前都执行有界完整扫描：刷新资料更新快照，重建索引重新建立检索数据；不宣传增量索引。根 HTML 为可重建派生副本，可能包含内部资料，不自动提交或公开发布。
- 项目复制/移动到另一目录或另一台机器时，由技能重新 attach 更新本机身份；旧登记不会自动跟随。不要让未知网页凭路径访问未登记项目。

## 验证与升级

升级需验证 file 快照、协议唤起、HTTP 阅读、源变更后刷新、任务线/原文/搜索、失败保留以及窄屏。安全检查覆盖未知身份、错误令牌、跨来源请求、路径越界和同名文件保护。源码单测不代替浏览器操作。

已有项目自己的 HTML 编年史工具不删除；新入口使用施工队统一运行时。更完整的资料格式适配按真实缺口演进，不强制旧项目改造整个文档体系。
