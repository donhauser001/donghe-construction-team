# Donghe Construction Team · Project Evolution

Version 0.9.0 packages engineering discipline, evidence-backed completion, source relationships, monthly archival, project-local code intelligence and a read-only evolution UI. The verified complete-package platform remains macOS arm64.

The first complete release is verified for **macOS arm64**, with Codex and Cursor terminal entrypoints. Download the platform package from GitHub Releases, extract it, and run `bin/install`. Python, the pinned graph engine and Chrome Headless Shell are included; first use needs no dependency download. Other platforms are not claimed as verified complete installations.

Artifacts use `docs/东合/`; local state and graph generations use `.donghe/`. Existing project sources stay in place. Missing history is not invented. Old receipts do not authorize new work. No eligible task means stop.

Work happens in the user's current physical workspace by default. Uncommitted changes are normal project state; Donghe does not automatically create a worktree, clone, or copied project unless the user explicitly requests isolation. Existing construction systems take precedence, and finding `docs/东合/` does not authorize automatic initialization or migration. `doctor` is for installation, upgrade, or runtime failures; project-side CLI adoption is explicit.

Independent documentation, investigation, and research branches may be delegated while the main process continues work that does not depend on them. Shared files have one writer, and delegated results are verified before integration. Documentation follows event updates: replace current state, append history, and keep entry pages link-only. A separate read-only decision-query skill may answer decisions but does not own construction state.

Version 0.9.0 adds a project-root HTML snapshot, explicit task-line grouping and an on-demand native reader helper. During authorized construction, `reader attach` creates the entry without governance initialization or migration. Refresh buttons rescan saved documents without completing tasks or modifying their authoritative sources. The complete installer registers the helper; the browser may ask for external-app consent once. No manually managed service is required. HTML is derived, may contain internal documents, and is not automatically committed or published.
