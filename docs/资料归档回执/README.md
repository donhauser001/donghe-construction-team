## 实际能力

- 六种资料按需创建/更新，文件级稳定ID和donghe-meta元标签；任务/日志/交接沿用现有格式，不建九套空文件。
- 显式关系和反向索引；完工沿derived_from反馈上游想法，重复finish幂等，关系不等于整项方向兑现。
- 只读归档预览、按月移动、原逻辑路径读取、冷扫描、恢复；原文/证据字节不变，共享指纹留在原位。
- 每自然月首次init/finish检查；本月、活跃记录、当前交接保留。没有常驻调度；闲置项目下次开工补检查。
- 进化史新增方向到任务关系、来源入口、资料类型筛选、已归档提示与缺失关系诊断。

## 明确边界

这次完成文件级关系和单写者按月归档纵切，不是完整历史迁移、章节事件协议或代码图谱。catalog返回元标签和短摘要，尚未做大规模分页。归档是可恢复逐文件操作，不是全批文件系统原子事务。纯冷档案缺少历史归档日志时，恢复标明transport-only，不宣称历史完整性已认证。
