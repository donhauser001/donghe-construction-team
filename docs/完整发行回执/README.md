## 边界与成本

首版不包括Windows/Linux完整运行包、实体手机实测、跨机器多写者、云同步、无事实源历史生成或高级图谱可视化。浏览器受控网络策略不等于操作系统网络沙箱，原生移动验收不能被Web截图替代。

图谱是策略选中且上游支持的源码范围，不代表所有语言和动态调用。更新源码后按需新建完整代，不冒充增量引擎；旧/失败代保留。1000条目录冷查询实测约422ms，但每页仍扫描元标签；没有承诺无限规模。

没有本轮计费token A/B数据，因此不声称节省百分比。给出可验证的输出限制、源码回读定位和索引复用事实。后续改进应由明确用户目标或新失败触发，不能因仍有可改之处就无限施工。
