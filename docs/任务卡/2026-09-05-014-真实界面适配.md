# 包内真实界面验收适配器

- 目标：无宿主浏览器能力时，用包内 Chrome 与标准库 CDP 执行最小真实交互验收。
- 写白名单：`scripts/donghe_ui.py`、`tests/test_ui.py`、本卡。
- 禁写：主 CLI、打包/版本、业务项目状态和外部页面。
- URL：仅初始 localhost origin；同源路径跳转允许，跨端口/主机请求由 CDP 拦截并记录，非 OS 网络沙箱。
- 动作：click CSS、fill CSS、assert text CSS、assert visible CSS、screenshot。
- 证据：冻结脱敏合同及哈希、授权、时间、每步输入身份、console/exception/网络违规、截图哈希和总判定。
- 失败：非零 CLI 退出且保留证据；缺二进制明确 unavailable。
- 预算：最多 50 步、单次 1–60 秒；始终清理临时 profile 与自启浏览器进程。
- 验收：真实 Chrome 完成点击→界面变化→断言→截图；纯截图仅 captured；异常与跨源外发必须失败。
