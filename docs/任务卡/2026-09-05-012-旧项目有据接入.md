# 旧项目有据接入

- 目标：只读扫描旧项目已有治理 Markdown，以原文哈希登记来源，再生成规范资料记录。
- 写白名单：`scripts/donghe_adopt.py`、`tests/test_adopt.py`、本卡。
- 禁写：旧项目、主 CLI、records 模块、版本文件和共享文档。
- 不变量：来源不搬不改；不推断历史状态或日期；不派任务；无 Git 项目也可用。
- 来源正本：`docs/东合/来源.json`，资料正文只保留人可读引用。
- 安全：排除 `docs/东合`、`.donghe`、`.git`、`node_modules`、`secrets` 和符号链接。
- 预算：最多 100 候选、单文件 256 KiB、总读取 20 MiB；返回截断标记。
- 验收：扫描入口/显式目录、预算与排除、接入幂等/更新门、缺源拒绝、安全原文回读、哈希陈旧、无 Git项目。
