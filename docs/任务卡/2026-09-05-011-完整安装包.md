- 授权：用户要求持续至全部完工，一次安装无需手工配置附加依赖。
- 写域：packaging、bin、scripts/build_release.py、scripts/install_release.py、相关测试与发行文档；独立 product-package worktree。
- 不变量：不改业务依赖、不覆盖独立第三方安装；固定版本与摘要；安装包首用不下载。

- 运行时：锁定 Python standalone 与 codebase-memory-mcp；第三方许可随包。
- 状态：实现及预发行审查通过；最终完整包构建与双端发行回执见 `docs/完整发行回执/release.json`。
