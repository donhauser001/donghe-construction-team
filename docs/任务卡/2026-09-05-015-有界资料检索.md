# 015 · 有界资料检索

- 目标：复用资料正本目录，提供只读、可分页、低 token 的筛选与关系查询。
- 写域：`scripts/donghe_catalog.py`、`tests/test_catalog.py`、本卡。
- 接口：`query(project, kind=None, text='', offset=0, limit=50)`；limit 上限 100，查询文本上限 256。
- 语义：记录保留 source path 与 archived 身份；只返回当前页记录的出入边，页外目标保留原 target ID；问题最多 100 条并报告总数。
- 预算：JSON 输出最多 128 KiB；超限先压缩展示字段但保留记录 ID 与全部关系事实，仍超限则明确报错。
- 合成验收：直接渲染 1000 条 synthetic 资料，避免 `records.create` 的重复全目录扫描；冷查询指定关键词、十页遍历无遗漏无重复，并检查每页输出预算。
- 证据（2026-09-05）：`python -m unittest tests.test_catalog -v` 为 3/3；1000 条独立冷查询命中 `S0777`，422.17ms，JSON 430 bytes。
- 已知成本：每次分页仍调用一次 `records.catalog`，十页遍历会重复扫描目录（本机整组夹具约 4.4s）；本卡保持只读适配边界，未修改 records/archive 正本实现。
